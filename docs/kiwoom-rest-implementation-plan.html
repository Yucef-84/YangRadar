YangRadar 키움 REST API 구현 계획안

한국 주식 키움 REST API 최신/지연 데이터 샘플 데이터 금지

목표는 사용자가 종목명을 검색했을 때 차트, 거래량, OBV, RSI, 심리도10, 외국인/기관 수급, 프로그램매매, 거래대금, 회전률을 한 화면에서 보는 웹앱을 완성하는 것이다.

1. 핵심 원칙

  • 운영 화면에는 가짜 OHLCV, 가짜 외국인/기관 수급, 가짜 프로그램매매 데이터를 표시하지 않는다.
  • 키움 REST API에서 받은 실데이터만 차트와 표에 사용한다.
  • 키움에서 제공하지 않거나 응답 파싱이 안 된 항목은 데이터 없음으로 표시한다.
  • 자동매매, 주문, 계좌 매매 기능은 이번 범위에서 제외한다.

2. 키움 REST API 기준

영역 키움 TR/API 후보 사용 목적

종목 검색 ka10099 종목정보 리스트 KOSPI/KOSDAQ 종목명, 종목코드 검색

3. 시스템 구조

Backend

  • FastAPI가 프론트 요청을 받는다.
  • KiwoomRestProvider가 키움 토큰 발급, 토큰 캐시, TR 요청을 담당한다.
  • SQLite는 종목 목록, 최근 조회 응답, 계산된 지표 캐시를 저장한다.
  • 모든 응답에는 data_quality를 포함한다.

Frontend

  • React 화면은 종목 검색, 상단 요약, 차트, 보조지표, 수급표, 프로그램매매표를 표시한다.
  • 데이터가 없는 패널은 빈 차트 대신 데이터 없음 상태를 보여준다.
  • 상단에는 키움 REST 연결됨, API 미설정, 인증 실패, 요청 제한 배지를 표시한다.

4. API 계약

Endpoint 역할

5. 구현 단계

단계 내용 완료 기준
1단계 키움 REST 인증, 토큰 발급, 토큰 캐시 구현 /api/health에서 연결 상태 확인 가능
2단계 종목 목록/검색 연결 삼성전자 외 전체 KOSPI/KOSDAQ 종목 검색 가능
3단계 현재가, 거래량, 거래대금 연결 상단 요약 영역이 키움 실데이터로 표시
4단계 일봉 차트 연결 및 OBV/RSI/심리도 계산 차트와 보조지표가 실데이터 기반으로 표시
5단계 외국인/기관 수급 누적 계산 5/20/60/120일 순매수와 비율 표시
6단계 프로그램매매 일별/누적 표시 비차익 또는 종목별 프로그램매매 추이 표시
7단계 테마/종목 설명 연결 테마 그룹 또는 업종 정보 표시

6. 테스트 시나리오

  • .env 없음: 앱은 켜지고 모든 데이터 패널은 API 미설정으로 표시된다.
  • 키움 인증 실패: 화면이 깨지지 않고 인증 실패 배지를 표시한다.
  • 키움 인증 성공: 삼성전자 현재가, 거래량, 일봉 데이터가 표시된다.
  • 일부 TR 실패: 실패한 패널만 데이터 없음으로 표시하고 나머지 패널은 유지한다.
  • 종목 검색: 삼성전자, 현대차, 에코프로, 한화에어로스페이스 검색이 가능하다.
  • 샘플 금지: 네트워크 실패 시 가짜 차트나 가짜 수급표가 절대 표시되지 않는다.

7. 운영 설정

KIWOOM_APP_KEY=발급받은_앱키
KIWOOM_SECRET_KEY=발급받은_시크릿키
KIWOOM_ACCOUNT_NO=필요시_계좌번호
KIWOOM_ENV=real
주의: 키움 REST 응답 필드명은 TR별로 다르므로, 최초 실제 키 연결 후 원본 응답을 1회 확인하고 파서를 확정해야 한다. 응답 파싱이 안 되는 항목은 샘플로 채우지 않고 unavailable로 둔다.

8. 최종 완료 기준

  • 사용자가 키움 API 키를 넣으면 실데이터 기반 대시보드가 열린다.
  • 검색, 차트, 거래량, 보조지표, 수급, 프로그램매매가 한 화면에서 확인된다.
  • 실데이터가 없는 경우에는 명확한 상태 메시지가 표시된다.
  • 자동매매 기능 없이 정보 확인용 대시보드로 안정적으로 동작한다.
